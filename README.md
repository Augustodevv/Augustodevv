## Projetos em destaque

### AgendaFlow AI

SaaS de agendamento para barbearias e salões. O cliente reserva pelo celular sem criar conta; o dono gerencia serviços, profissionais, jornada e agenda, e envia lembretes pelo WhatsApp para reduzir faltas. Multi-tenant com isolamento por empresa, prevenção de reserva duplicada garantida pelo PostgreSQL e testes de integração e E2E (Playwright, com checagem de acessibilidade) no CI.

**Stack:** Next.js, React, TypeScript, Tailwind CSS, PostgreSQL, Prisma, Better Auth, Vitest e Playwright  
[Ver repositório](https://github.com/Augustodevv/agendaflow-ai)

### Finanças SaaS

Aplicação Full-Stack de gestão financeira pessoal com isolamento por organização, autenticação JWT, dashboard e CRUD de transações. O plano Premium é apenas uma simulação de regra de negócio; não existe cobrança real.

**Stack:** React, TypeScript, Tailwind CSS, Fastify, Node.js e PostgreSQL  
[Ver repositório](https://github.com/Augustodevv/meu-primeiro-saas)

### AtendeFlow

Painel de oportunidades para pequenos negócios. Permite cadastrar contatos, acompanhar negociações, definir próximos passos e visualizar indicadores, usando uma API Node.js e persistência em SQLite. Inclui um botão de **sugestão de próximo passo com IA** (API da Anthropic), com regras locais como alternativa quando não há chave configurada. Os dados pessoais do contato não são enviados à IA.

**Stack:** Node.js, SQLite, HTML, CSS e JavaScript  
[Ver repositório](https://github.com/Augustodevv/atende-flow)

### Ceres Brigadeiros

Experiência de encomendas para uma brigadeiria, com catálogo, filtros, personalização de bolos, carrinho e checkout pelo WhatsApp. O repositório inclui versões estática e React.

**Stack:** React, Vite, HTML, CSS e JavaScript  
[Ver repositório](https://github.com/Augustodevv/site-doceria)

### Portfólio pessoal

Site responsivo para apresentar serviços, processo de trabalho e estudos em automações e agentes de IA. Construído sem framework para destacar HTML semântico, CSS e interações em JavaScript.

**Stack:** HTML, CSS e JavaScript  
[Ver código](https://github.com/Augustodevv/site-augustodevv)

### Oketa Arquitetura

Projeto técnico de site institucional para um escritório de arquitetura do Litoral Norte de São Paulo. Reúne apresentação, serviços, galeria e contato em uma página responsiva.

**Stack:** HTML, CSS e JavaScript  
[Ver repositório](https://github.com/Augustodevv/site-oketa)
